# Day 1 - Infrastructure Cost Optimization

## 1. What is Cloud Computing?

Cloud Computing means using computing resources such as servers, storage, databases, networking, and software through the internet instead of maintaining physical hardware.

### Examples
- Amazon Web Services (AWS)
- Microsoft Azure
- Google Cloud

### Benefits
- No need to buy physical servers
- Pay for resources based on usage
- Easy to scale resources
- Faster deployment
- Flexible infrastructure

---

## 2. What is Infrastructure?

Infrastructure is the collection of resources required to run an application or service.

### Main Infrastructure Components

1. Servers
2. Storage
3. Databases
4. Networking
5. Load Balancers

### Example

An online shopping website may need:

- Web/Application Server → Runs the application
- Database → Stores customer and product information
- Storage → Stores images and files
- Network → Connects different components
- Load Balancer → Distributes user traffic

---

## 3. What is Infrastructure Cost Optimization?
Infrastructure Cost Optimization is the process of reducing unnecessary infrastructure expenses while maintaining performance, reliability, security, and availability.

### Simple Example

Suppose a company uses a large server costing $100 per month.

But the server is using only 20% of its capacity.

The company can replace it with a smaller server costing $60 per month.

### Result

Before Optimization = $100/month

After Optimization = $60/month

Estimated Saving = $40/month

---

## 4. Why is Cost Optimization Important?

Companies optimize infrastructure costs because:

1. It reduces cloud expenses.
2. It prevents resource wastage.
3. It improves resource utilization.
4. It increases operational efficiency.
5. It helps improve business profitability.
6. It allows companies to use resources efficiently.

---

## 5. Common Infrastructure Cost Problems

### 1. Over-Provisioning

Providing more resources than the application actually needs.

Example:
A server has 16 GB RAM but the application uses only 4 GB.

### 2. Idle Resources

Resources that are running but not being used.

Example:
A development server running 24/7 even when nobody is using it.

### 3. Unused Storage

Storage containing unnecessary or old data.

Example:
Old backups and unused files occupying storage space.

### 4. Oversized Resources

Using expensive and powerful resources when smaller resources are sufficient.

### 5. Unnecessary Backups

Keeping old backups and snapshots that are no longer required.

---

## 6. Basic Cost Optimization Methods

Some common methods are:

- Right-Sizing resources
- Auto Scaling
- Removing unused resources
- Storage optimization
- Using reserved pricing for predictable workloads
- Using Spot Instances for suitable workloads
- Monitoring resource utilization

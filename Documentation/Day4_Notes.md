# Day 4 - Cost Optimization Techniques## 1. Right-Sizing

Definition:
Choosing the correct resource size based on actual usage.

Example:
A large server running at only 20% CPU can be replaced with a smaller server.

Benefits:
- Reduces cost
- Improves resource utilization## 2. Auto Scaling

Definition:
Automatically increases or decreases servers based on traffic.

Example:
During high traffic → Add servers.
During low traffic → Remove servers.

Benefits:
- Saves money
- Improves performance


## 3. Reserved Instances

Definition:
Reserve cloud resources for 1 or 3 years at a discounted price.

Benefits:
- Lower cost than on-demand resources
- Suitable for predictable workloads
## 4. Spot Instances

Definition:
Unused cloud capacity available at a lower price.

Benefits:
- Very low cost
- Useful for testing and batch jobs

Limitation:
Can be interrupted by the cloud provider.
## 5. Storage Optimization

Definition:
Move rarely used files to cheaper storage.

Examples:
- Archive old files
- Delete unnecessary backups
- Use lifecycle policies

Benefits:
- Reduces storage costs
## Comparison Table

| Technique | Purpose | Cost Saving |
|------------|---------|-------------|
| Right-Sizing | Reduce resource size | High |
| Auto Scaling | Match resources to demand | High |
| Reserved Instances | Long-term discount | Medium |
| Spot Instances | Use unused capacity | Very High |
| Storage Optimization | Reduce storage costs | Medium |
## Advantages

1. Reduces cloud spending
2. Improves efficiency
3. Eliminates waste
4. Better resource management
5. Increases business profitability
## Summary

Today I learned various cloud cost optimization techniques such as Right-Sizing, Auto Scaling, Reserved Instances, Spot Instances, and Storage Optimization. These techniques help organizations reduce cloud expenses while maintaining performance and reliability.

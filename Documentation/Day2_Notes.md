# Day 2 - Cloud Resources

## EC2
- EC2 stands for Elastic Compute Cloud.
- It is a virtual server in the cloud.
- Used for hosting applications and websites.
- Cost depends on instance size and running hours.

## S3
- S3 stands for Simple Storage Service.
- Used to store files, images, videos and backups.
- Cost depends on storage usage.

## RDS
- RDS stands for Relational Database Service.
- Used to manage databases.
- Cost depends on database size and storage.

## Load Balancer
- Distributes traffic across multiple servers.
- Improves availability and performance.
- Cost depends on traffic and usage.

## Service Cost Mapping

| Service | Purpose | Cost Depends On |
|----------|----------|----------------|
| EC2 | Virtual Server | Instance Size, Hours |
| S3 | Storage | Storage Used |
| RDS | Database | DB Size, Storage |
| Load Balancer | Traffic Distribution | Requests, Hours |
